# 配置系统完整说明

## 🎯 设计目标

建立简洁灵活的配置系统，确保：
1. **环境变量可以覆盖默认值**
2. **年级配置提供参考基准**
3. **配置灵活，可上下浮动10%左右**
4. **用户体验友好**
5. **配置变量语义清晰**

## 📊 配置优先级层次

### 1. 字数配置优先级
```
环境变量 > 年级默认值
```

### 2. 错误数量配置优先级
```
环境变量 > 年级默认值
```

### 3. 其他配置优先级
```
环境变量 > 代码默认值
```

> 💡 **注意**：年级配置只是参考基准，系统不会强制限制。你可以灵活调整，建议在基准值上下浮动10%左右。

## 🔧 具体实现逻辑

### 字数配置流程
```python
if 字数未设置:
    if 环境变量设置了字数:
        使用环境变量字数 ✅
    else:
        使用年级默认字数 📚
else:
    使用已设置的字数

# 显示建议范围（仅供参考）
print(f"💡 {年级}建议范围：字数{基准值*0.9}-{基准值*1.1}字（仅供参考）")
```

### 错误数量配置流程
```python
if 错误数量未设置:
    if 环境变量设置了错误数量:
        使用环境变量错误数量 ✅
    else:
        使用年级默认错误数量 📚
else:
    使用已设置的错误数量

# 显示建议范围（仅供参考）
print(f"💡 {年级}建议范围：错误数量{基准值*0.8}-{基准值*1.2}个（仅供参考）")
```

## 💡 使用场景示例

### 场景1：使用年级默认值
```bash
# .env 文件不设置字数相关配置
DEFAULT_GRADE=二年级
DEFAULT_THEME=春游
DEFAULT_EXERCISE_COUNT=3
DEFAULT_MODE=misspelling
```
**结果**：使用二年级默认字数65字，默认错误数量5个

### 场景2：环境变量在合理范围内
```bash
# .env 文件设置合理字数
DEFAULT_GRADE=二年级
DEFAULT_EXERCISE_LENGTH=70
DEFAULT_ERROR_COUNT=6
```
**结果**：使用环境变量设置的字数70字，错误数量6个

### 场景3：环境变量灵活调整
```bash
# .env 文件设置自定义字数
DEFAULT_GRADE=二年级
DEFAULT_EXERCISE_LENGTH=120  # 超出建议范围，但系统允许
DEFAULT_ERROR_COUNT=10       # 超出建议范围，但系统允许
```
**结果**：
- 字数：使用环境变量设置120字 ✅
- 错误数量：使用环境变量设置10个 ✅
- 系统会显示建议范围，但不强制限制

### 场景4：自定义配置

config = {

## 🔄 配置变量说明

### 配置变量名

语义清晰
UI
```python
DEFAULT_CONFIG = {
    "grade": "二年级",                    # 年级
    "theme": "random",                   # 主题
    "exercise_length": 60,               # 每篇练习的字数
    "error_count": 5,                    # 每篇练习的错误数量（错别字/用词不当）
    "exercise_count": 5,                 # 要生成的练习篇数
    "mode": "misspelling"                # 练习模式
}
```

### 环境变量对应关系

| 变量名 | 说明 |
|----------|------|
| `DEFAULT_EXERCISE_LENGTH` | 每篇练习的字数 |
| `DEFAULT_ERROR_COUNT` | 每篇练习的错误数量 |
| `DEFAULT_EXERCISE_COUNT` | 要生成的练习篇数 |

### 重构优势

1. **语义清晰**：变量名一看就知道用途
2. **避免混淆**：不再有多个"count"变量
3. **易于维护**：代码可读性大大提高
4. **配置友好**：环境变量名称更加直观
