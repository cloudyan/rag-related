# 小学生语文方格纸A4 PDF模板

## 📝 功能说明

这个模块可以生成标准的小学生语文方格纸PDF模板，方便打印使用，适合：
- 小学生练习写字
- 语文作业书写
- 错别字纠错练习（包含答案）
- 用词不当纠错练习（包含答案）
- 作文练习

## 🎯 模板特点

- **标准A4尺寸**：210mm × 297mm
- **方格大小**：7mm × 7mm（适合小学生书写）
- **网格线**：细线网格，每5个格子有粗线分隔
- **页边距**：15mm（留出足够书写空间）
- **网格数量**：约30列 × 40行

## 🚀 使用方法

### 1. 生成单页方格纸
```bash
cd playground/001-typos
uv run simple_grid_paper.py
```

### 2. 生成多页方格纸
```python
from simple_grid_paper import create_multi_page_grid_paper

# 生成10页方格纸
create_multi_page_grid_paper("dist/方格纸_10页.pdf", 10)
```

### 3. 自定义页数
```python
from simple_grid_paper import create_multi_page_grid_paper

# 生成20页方格纸
create_multi_page_grid_paper("dist/方格纸_20页.pdf", 20)
```

## 📁 输出文件

运行后会在 `dist/` 目录下生成：
- `方格纸_单页.pdf` - 单页方格纸模板
- `方格纸_多页.pdf` - 多页方格纸模板（默认10页）

## 🖨️ 打印建议

1. **纸张选择**：建议使用A4白纸
2. **打印设置**：选择"实际大小"或"100%"缩放
3. **双面打印**：可以节省纸张
4. **装订方式**：可以装订成练习本

## ⚙️ 自定义参数

如果需要调整方格大小或其他参数，可以修改 `simple_grid_paper.py` 中的：

```python
# 设置参数
margin = 15 * mm      # 页边距
grid_size = 7 * mm    # 每个方格的大小
```

## 📊 模板规格

| 项目 | 规格 |
|------|------|
| 页面尺寸 | A4 (210mm × 297mm) |
| 方格大小 | 7mm × 7mm |
| 页边距 | 15mm |
| 网格数量 | 约30列 × 40行 |
| 粗线间隔 | 每5个格子 |
| 适用年级 | 小学1-6年级 |

## 🎨 样式特点

- **细线网格**：0.3pt细线，不干扰书写
- **粗线分隔**：1pt粗线，便于定位和计数
- **居中对齐**：文字在方格中居中显示
- **清晰打印**：适合黑白打印

## 📝 使用技巧

1. **书写建议**：每个字占一个方格，标点符号也占一个方格
2. **行距控制**：每行之间留出适当空间，便于阅读
3. **页边利用**：可以在页边空白处做笔记或标记
4. **重复使用**：可以多次打印，制作练习本

## 🔄 批量生成

如果需要大量方格纸，可以：

```python
# 生成不同规格的方格纸
for pages in [5, 10, 20, 50]:
    create_multi_page_grid_paper(f"dist/方格纸_{pages}页.pdf", pages)
```
